# Práctica de Visión Artificial: Clasificador de Imágenes con Keras

![Status](https://img.shields.io/badge/status-en%20desarrollo-yellow)

Proyecto para la asignatura **Sistemas Inteligentes** de la Universidad de Alicante. El objetivo es implementar y optimizar Redes Neuronales (MLP y CNN) para clasificar imágenes del dataset CIFAR-10.

---

### 🎯 Objetivos de la Práctica

*   Comprender el funcionamiento de **Redes Neuronales Convolucionales (CNN)** y **Perceptrones Multicapa (MLP)**.
*   Conocer en detalle el algoritmo de **backpropagation**.
*   Utilizar la librería **Keras (TensorFlow)** para implementar redes neuronales de forma efectiva.
*   Resolver un problema real de clasificación de imágenes.
*   Ajustar los hiperparámetros de una red para maximizar su tasa de acierto.
*   Utilizar **Matplotlib** para la visualización de resultados.

---

### 💻 Stack Tecnológico

*   **Python**
*   **Keras (TensorFlow)**
*   **Pandas**
*   **Numpy**
*   **Matplotlib**
